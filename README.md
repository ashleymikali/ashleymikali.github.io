# Portfolio Website

Personal portfolio and project showcase built with Quarto and deployed via GitHub Pages.

🔗 **Live Site:** [ashleymikali.com](https://ashleymikali.com)

## About

This repository contains the source code for my data science portfolio, featuring projects in statistical analysis, machine learning, and data visualization. The site is built using Quarto, a scientific and technical publishing system, and styled with custom SCSS.

## Featured Projects

- **[Spending Habits Analysis](https://ashleymikali.com/projects/spending-behavior-model/spending-habits-analysis.html)** - Logistic regression analysis of behavioral survey data (6000+ responses) examining relationships between financial behaviors and spending habits
- **[Census Income Prediction](https://ashleymikali.com/projects/census-data-hackathon/ar_hackathon.html)** - Classification model using XGBoost to predict income thresholds from U.S. Census data (86.6% accuracy, 3rd place finish)
- **[Annals of Eugenics Analysis](https://ashleymikali.com/projects/eugenics-journal-graphs/aoe-graphs.html)** - Historical dataset construction and analysis of academic publication trends

## Local Development

To run this site locally:

1. Install [Quarto](https://quarto.org/docs/get-started/)
2. Clone this repository
```bash
git clone https://github.com/ashleymikali/ashleymikali.github.io.git
cd ashleymikali.github.io
```
3. Preview the site
```bash
quarto preview
```

## Building

To build the site:
```bash
quarto render
```

The rendered site will be generated in the `_site` directory.
